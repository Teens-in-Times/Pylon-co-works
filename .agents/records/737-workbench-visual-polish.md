## 目标与范围

将聊天页卡片之外的工作台、导航与主要内置页面一并打磨。现代 GUI 统一选中态与页面材质，经典终端维持紧凑的信息布局。沿用已有主题设置、首方包分工和侧栏布局协议。

## 改动清单

| 范围 | 结果 |
| --- | --- |
| 标题栏 | 现代页签用浅色选中底，文档与设置使用各自图标。现代菜单调整行距和边界。终端页签使用等宽字形，保留底部选中线。 |
| 聊天与两侧栏 | 现代模式的默认用户标记换成图标，工具状态靠近名称，会话和资源标签同步选中态。终端资源标签变紧凑，资源空态改用分隔线。 |
| 首页 | 现代模式区分起始操作与下方列表。终端收紧页头和列表。去除重复侧栏标题与教程的手写编号。 |
| 搜索、历史、日志 | 搜索和历史使用带图标的统一筛选字段，键盘焦点落在外框。终端结果与日志行减少占高，宽窗搜索摘要用单行。现代日志页头与筛选区层级更清晰。 |
| 网关 | 现代总览清楚显示计数，展开的路由使用统一选中底。终端用较密的路由行与方角控件。 |
| 文件、网页、文档 | 文件树和页签同步选中态，终端工具栏与文件项缩减行高。浏览器和文档共用轻分隔的工具栏外观。 |
| 设置与插件 | 设置各域与分区去掉叠加标记，插件管理的托管页与授权前宿主页均使用连续列表。 |

## 样式归属与测试处置

- 模式级联保留在既有样式所有者中，页面节点仅添加必要布局锚点。搜索工具的基础结构和插件管理的行布局继续使用 utilities。表面、边界、选中颜色复用现有语义变量。
- 复用工作台、页签、设置、文件、插件和浏览器相关的现有测试。没有改动测试断言。额外用双模式浏览器和原生验收检查 CSS 级联与几何。
