### 本地预演构建

- 首次 `--build` 在 `build:plugin-sdk` 失败：`error TS5023: Unknown compiler option '--ignoreConfig'`。根因是本地 `node_modules` 陈旧——`package.json` 要求 `typescript ~6.0.3`，实际装的是 5.9.3（dependabot 升 TS 后未重装）。`bun install --frozen-lockfile` 后 tsc 6.0.3 就位，锁文件未变。
- 重跑全链 exit 0。构建目标盘余量 16.0 GiB（守卫阈值 10 GiB）。

### PR 与发布

- PR #697 首跑 CI 红在 `plugin_process::tests::job_object_kills_descendant_process_tree`（`descendant still running: "conhost.exe","1856"`）：2s 进程树收敛窗口在 CI 争抢下被 conhost 占用已退出进程的 PID，与本次改动无关（本次只改版本号）。`gh run rerun --failed` 后 attempt 2 全绿，PR 合并。
