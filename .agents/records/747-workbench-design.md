## 页面与交互

| 范围 | 可观察的行为 |
| --- | --- |
| 聊天与输入 | 现代模式用角色标记和独立阅读列区分问答，资源预览和附件动作在内容旁。终端的问题行使用提示符与细线，工具和资源信息保持紧凑。草稿、附件条和动作各有空间，输入框在达到高度上限后可继续滚动。发送、入队、停止各有图标与读屏标签。 |
| 窗口与概览 | 首页并列展示继续工作入口与统计。现代模式的列表按内容区宽度排版，终端的 Agent 行高 34px。分区导航将焦点移至选中的内容，首次启动仅显示可执行的入口。页签与左右栏调整了文字留白、选中和焦点反馈。 |
| 窄窗 | 双侧栏同时展开时，沿用 railLayout 的有效宽度投影，给阅读列留出空间。用户手动保存的栏宽仍可在宽窗恢复。窄侧栏里的新会话按钮保持单行，现代会话行将时间放在名称下方。 |
| 搜索与存档 | 搜索结果在原文中高亮字面关键词。工作区文件搜索复用同一 Solid 组件。现代存档把日期放在标题下方，终端宽列保留同行；实际可用宽度不足时，操作自然分行。 |
| 文件、浏览器、文档 | 文件页签使用文件树已有的类型图标，空编辑区随剩余空间排版。浏览器地址栏聚焦时整框可见；选中页签和文档就绪状态随界面模式着色。 |
| 运行日志与网关 | 普通日志可选择文本，有详情的行可经键盘展开。窄列把消息放在元数据下方。网关首页在现代模式使用四项统计面板，终端使用并列计数，路由和凭据操作沿用既有接口。 |
| 设置与插件 | 模板库在现代模式显示预览画廊，在终端模式使用缩略索引。当前模板和覆盖范围可见，应用或恢复进行中可阻止重复操作。设置分区、布局编辑器、插件授权前的宿主页与授权后的托管页均有调整；窄窗仍显示插件状态。 |

首方样式继续随原包的 `styleAssets` 装载与回收，主题由原有预设和 CSS 变量供给。视图、输入动作和托管管理页沿用现有插件接口。三组并行施工分别负责聊天、导航与首页、设置与插件，主 agent 整合内置工具页、窄窗复验与全量门禁。

深色复验发现两处来源不同的配色问题。Tokyo Night 的根元素提前按浅色求值，现由皮肤投影同步 html 与 body 的方案，并在卸载时还原。现代会话名与身份按钮的文字对比度实测为 6.42:1，浅色模式为 11.99:1。五套终端出厂预设原先都写入了白色中控底色；现在按钮随各自配色。Amber CRT 的四个下方控件实测为透明底，编辑模型配色仍可单独覆盖。已有保存主题继续沿用其设置，重新选择出厂模板即可取得新版颜色。

## 测试处置

- `ChatView.css.test.ts` 清除了针对已退役的空态源码及某一种 transform 拼写的断言。有效的消息行对齐契约仍受测试覆盖。
- `InputBar.solid.test.tsx` 验证同一个按钮在发送、停止、入队、回到停止时的 SVG 变化，以及固定终端输入区移除附件后恢复高度。
- `Settings.a11y.solid.test.tsx` 原测试打开模板页、按 CSS 类查找一个已去除的折叠包装。现在进入侧栏设置，实际折叠和展开模块，检验内容显隐与 aria-expanded；同时检查域导航与分区按钮的焦点和当前位置。
- `TemplateLibrary.globalPresets.solid.test.tsx` 按有名称的模板定位，验证恢复中的互斥与错误反馈。`OverviewSheetView.visual.solid.test.tsx` 检查首启入口和分区焦点。
- `railLayout.test.ts` 验证窄窗有效宽度与宽窗偏好恢复。`RuntimeSheetView.solid.test.tsx` 同时覆盖有详情和无详情的日志。
- `SearchSheetView.solid.test.tsx` 和 `searchNavigation.integration.solid.test.tsx` 按可访问的结果按钮操作，验证命中词、全文与跨会话导航。文本节点可以在高亮处分割。
- `skinProjection.test.ts` 覆盖文档根与 body 的明暗方案同步及卸载还原。工作台皮肤 fixture 仅更新本次调整的终端出厂字段，15 个 fixture 均通过契约检查。
